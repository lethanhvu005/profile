# Project illustrations

Created with the built-in image generation tool. These are conceptual illustrations,
not screenshots of the actual products. Two assets are reused across four projects.

## portfolio.png

Use case: ui-mockup. Asset type: landscape portfolio project illustration. Create a polished conceptual product mockup: Personal portfolio website displayed on a laptop, elegant charcoal interface with amber accents, project cards and abstract avatar silhouette. Studio 3D render with softly lit neutral background, complete devices centered with generous margins, realistic readable interface hierarchy, minimal English labels only, no brand logos or watermarks. This is illustrative concept art, not a screenshot of an actual product.
